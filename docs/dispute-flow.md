# 争议（Dispute）流程

```
╔══════════════════════════════════════════════════════════════════════════╗
║                        HumanHouse 争议仲裁流程                          ║
╚══════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────┐
│ ① 发起争议（raiseDispute）                                          │
│                                                                     │
│   发起人                                                             │
│     │                                                               │
│     ▼                                                               │
│   需要先 approve HumanHouse 持有 disputeDeposit（CORN）              │
│     │                                                               │
│     ▼                                                               │
│   raiseDispute(marketId, disputeType, reason)                       │
│     │                                                               │
│     ├─ disputeType = OracleResult    → 争议预言机结果（结算错误）     │
│     └─ disputeType = MarketContent   → 争议市场内容（问题/规则不当）  │
│                                                                     │
│   抵押 CORN 转入 HumanHouse 合约（锁定）                             │
│   争议状态 = Active，投票期 = 5 天（votingPeriod）                   │
│   deadline = block.timestamp + 5 days                                │
│                                                                     │
│   ⚠️ 需要 approve HumanHouse 持有抵押代币                            │
└─────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────┐
│ ② 投票（vote）                                                       │
│                                                                     │
│   其他用户（持 CORN）                                                 │
│     │                                                               │
│     ▼                                                               │
│   需要 World ID 验证（当前模拟，待真实集成）                          │
│   vote(disputeId, support=true/false, root, nullifierHash, proof)   │
│     │                                                               │
│     ├─ support = true  → votesFor++                                 │
│     └─ support = false → votesAgainst++                             │
│                                                                     │
│   同一 World ID nullifier 只能投一次（防女巫）                       │
│   投票期间：< deadline                                               │
└─────────────────────────────────────────────────────────────────────┘
        │
        ▼  (5天投票期结束)
┌─────────────────────────────────────────────────────────────────────┐
│ ③ 执行争议（executeDispute）                                         │
│                                                                     │
│   任何人在 deadline 后调用                                           │
│     │                                                               │
│     ▼                                                               │
│   executeDispute(disputeId)                                         │
│     │                                                               │
│     ├─ votesFor > votesAgainst  ──► 争议通过（Approved）             │
│     │     │                                                       │
│     │     ├─ 返还发起人抵押（deposit）                               │
│     │     │                                                       │
│     │     └─ 如果是 OracleResult 类型：                              │
│     │           └─ 调用 PredictionMarket.disputeResolve()           │
│     │              → 翻转市场结算结果（true ↔ false）                │
│     │              → 已领取的奖励无法追回                            │
│     │                                                              │
│     └─ votesAgainst >= votesFor  ──► 争议拒绝（Rejected）            │
│           │                                                        │
│           └─ 抵押 CORN 没收（归合约 owner 所有）                     │
│              → owner 可调用 withdrawFees() 提取                     │
│                                                                     │
│   争议状态变为终态（不可再修改）                                     │
└─────────────────────────────────────────────────────────────────────┘


╔══════════════════════════════════════════════════════════════════════════╗
║  争议类型对比                                                          ║
╠══════════════════════════════════════════════════════════════════════════╣
║                                                                        ║
║  OracleResult（预言机结果争议）                                         ║
║    场景：Chainlink 给出的价格被判定为错误                               ║
║    通过后：翻转市场结算结果（YES↔NO）                                   ║
║    已领取：无法追回（领走就领走了）                                      ║
║    未领取：按新结果重新结算                                              ║
║                                                                        ║
║  MarketContent（市场内容争议）                                          ║
║    场景：市场问题不当、规则有问题                                        ║
║    通过后：仅记录争议结果（标记 Approved），不改变结算                   ║
║    用途：社区监督，为后续治理提供依据                                    ║
║                                                                        ║
╚══════════════════════════════════════════════════════════════════════════╝


╔══════════════════════════════════════════════════════════════════════════╗
║  当前限制（已知问题）                                                    ║
╠══════════════════════════════════════════════════════════════════════════╣
║                                                                        ║
║  1. 抵押金额固定（disputeDeposit，owner 可调）                         ║
║     → 无法动态调整，大市场抵押太小                                      ║
║                                                                        ║
║  2. 投票权重相同（1票=1票）                                             ║
║     → 无法体现持仓大小的影响                                            ║
║                                                                        ║
║  3. 翻转后已领取奖励无法追回                                            ║
║     → 先领的人无风险，后领的人受损                                      ║
║                                                                        ║
║  4. 投票期固定 5 天                                                     ║
║     → 小争议拖延太久，大争议时间不够                                    ║
║                                                                        ║
║  5. World ID 尚未真实集成（当前模拟）                                   ║
║     → 投票去中心化程度存疑                                              ║
║                                                                        ║
╚══════════════════════════════════════════════════════════════════════════╝
```
