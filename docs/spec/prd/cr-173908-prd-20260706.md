---

## 1. 背景与问题陈述

Prediction Master 当前处于多阶段演进中，存在**明确的"未完成"边界**：

- `HumanHouse._verifyWorldId()` 为 TODO，当前直接返回 `true`（真实 World ID 信任层未集成）。
- `TokenHouse`（Phase 3 经济院，OZ Governor）合约**尚未实现**。
- 治理处于从单管理员向多签+Timelock 过渡阶段，Phase 3 双院制尚未闭环。
- `executeDispute` **未实现裁决副作用**（GAP-1）。

核心矛盾：链下/跨合约依赖（World ID、治理、Oracle 裁决）尚未完成，但开发仍需在无外网 RPC 的本地环境中获得**可重复、可回归、CI 可跑**的测试保护，避免"未完成"演变为"不可测"。

## 2. 目标

1. 在**零外部 RPC** 的本地环境（anvil + Foundry cheatcodes）下，对所有已存在的合约逻辑建立可重复测试。
2. 复用既有 mock 范式（`OracleAdapter` 的 `MockAggregator`），将"未完成依赖"以可替换 stub 隔离，使信任层缺失不阻塞业务测试。
3. 为尚未实现的治理组件（TokenHouse）与部署流程建立**骨架/不变量测试**，使未来集成有回归锚点。
4. 显式登记因"未完成"产生的实现缺口（GAP-1 / GAP-2），以追踪测试暴露而非掩盖。

## 3. 非目标（本期不做）

- **不**实现 World ID 真实集成（`_verifyWorldId` 保持返回 `true`）。
- **不**实现 `TokenHouse` 治理合约（仅建骨架 harness 与阈值快照 helper）。
- **不**实现 GAP-1 的裁决副作用（仅以占位守卫追踪）。
- **不**搭建前端测试（vitest / wagmi test），本期范围限定**仅合约侧**（决策 D2）。
- **不**改造 `HumanHouse` 接口以支持 World ID 地址注入（决策 D3 暂缓）。

| 角色 | 关注点 |

## 5. 功能范围

- **单元测试**：补强 `HumanHouse`（防重复投票、投票期、执行时间窗、二次执行、withdrawFees）与 `GovCrownToken`（委托前投票权、1:1 包装完整性）。
- **集成测试**：治理委托链路（`GovernanceIntegration`）+ 部署所有权转移不变量 dry-run（`DeployDryRun`）。
- **缺口追踪**：GAP-1 占位守卫（pass 不阻塞）、GAP-2 登记于文档。
- **构建说明**：`Makefile` 标注零外部 RPC、纯 anvil 运行约定。

## 7. 验收标准

1. **AC-1**：在具备 Foundry 的环境执行 `forge test -vvv`（即 `make test`）可全量运行，无需任何外部 RPC / API Key。
2. **AC-2**：新增测试覆盖 `HumanHouse` 的 `already voted` / `voting ended` / `voting not ended` / `not active` 四条回滚路径及 `withdrawFees` 没收逻辑。
3. **AC-3**：`GovCrownToken` 委托前投票权为 0、包装 1:1 完整性有断言。
4. **AC-4**：治理集成骨架可验证委托链路（包装→委托→获投票权），并为 TokenHouse 预留提案阈值快照。
5. **AC-5**：部署 dry-run 断言 `market/token.owner == Timelock`、`Timelock` 自管 admin、Safe 为 proposer、`Executor == address(0)`。
6. **AC-6**：GAP-1 / GAP-2 在文档与测试中以可检索方式登记。

> ⚠️ 当前执行环境 GitHub 访问被重置，**无法安装 Foundry**，AC-1~AC-5 的代码已编写但**未实跑验证**。本地验证命令：`cd futureWorldCorn && foundryup && make test`。

## 8. 约束

- 测试**必须**纯本地（anvil + `vm.warp/prank/startPrank`），禁止 `ffi` 依赖外网或真实 proof。
- 复用既有 `MockAggregator` 范式，不引入新第三方 mock 框架。
- 所有回滚断言**必须**匹配合约真实 error 字符串（如 `"already voted"`），与源码一致。

## 9. 依赖与缺口

| 项 | 类型 | 处理 |
|----|------|------|
| World ID 未集成 | 外部依赖未完成 | stub 隔离（D1），不阻塞 |
| TokenHouse 未实现 | 内部未完成 | 骨架 harness + 阈值快照 |
| **GAP-1** `executeDispute` 无裁决副作用 | 实现缺口（关键） | 占位守卫追踪，单独立项 |
| **GAP-2** `HumanHouse` 无 external `pause()` | 实现缺口（次要） | 文档登记，建议补 onlyOwner pause/unpause |

- 测试可重复率：100%（无 flaky，无外部依赖）。

- 缺口可见性：GAP-1/GAP-2 在 execute 记录与本文档均可检索。
