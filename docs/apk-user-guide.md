## 1. 这是什么

**预测大师**是一个基于区块链的预测市场应用：你可以看到"明天会下雨吗？""某球员会进几个球"等问题，用 **CORN 代币**下注"会（YES）/ 不会（NO）"。市场到期结算后，猜对的人按投入比例瓜分奖池。同时支持创建市场、参与争议仲裁和社区治理。

本说明适用于手机端（Android APK）。所有交易都在链上完成，公平透明、无法篡改。

## 2. 开始前准备

### 2.1 安装手机钱包

应用通过 **MetaMask**（当前版本内置）或其他支持 WalletConnect 的钱包完成登录和签名。请先安装：

- **MetaMask**：各大应用商店搜索下载

### 2.2 网络要求

- App 需要能访问 **World Chain Sepolia**（测试网）节点
- 部分网络环境（如国内需科学上网）下，钱包链接 WalletConnect 中继可能需要全程开梯子/VPN，**且要开启 VPN 全局或 TUN 接管**（否则深链调起钱包后可能一直"正在连接"）。与钱包交互期间请保持网络稳定
- 如果刷新不出市场列表，可到 **底部导航 更多 → 网络设置** 中更换 RPC 节点

### 2.3 获取测试用 CORN 与 ETH

- 下注需要 **CORN** 代币，交易签名需要少量 **ETH** 支付 Gas（测试网可从水龙头领取）
- CORN 总量 10 亿，除非参与治理/空投，正常用户默认有少量测试额度

## 3. 连接钱包

1. 打开 App，进入 **底部导航 更多 → 网络设置**
2. 点击 **连接钱包 (WalletConnect)**，弹出钱包列表，选择 **MetaMask**（当前内置钱包）
3. 手机自动跳转到钱包 App：
   - **首次使用**：钱包弹出授权"连接"界面 → 确认连接
   - 确认后自动跳回 App，设置页显示"已连接钱包（WalletConnect）"及你的钱包地址即连接成功
4. 连接后即可在首页下注；每次下注/领取/创建前，钱包会弹出签名确认，确认即执行

> 常见问题：如果点了钱包一直停在"正在连接"或没反应，多半是 VPN 未全局接管或网络断连，请检查 VPN 后重试。

## 4. 主要功能

App 底部为四个主菜单 Tab：**首页 / 投资 / 治理 / 更多**，下文所有路径均从底部导航栏进入。

| 入口 | 功能 |
|------|------|
| 底部导航 **首页** | 浏览全部市场、搜索、按分类/状态筛选 |
| 底部导航 **投资** | 我的持仓、可领取奖励、已下注记录 |
| 底部导航 **治理** | 参与提案投票（需持有 govCORN） |
| 底部导航 **更多** | 委托管理、争议、创建市场、权限管理、网络设置（含连接钱包） |

---

## 5. 下注（玩一个市场）

1. 底部导航 **首页** 点击感兴趣的市场，进入详情页
2. 看 **YES（会）/ NO（不会）** 两边的资金池、赔率和截止时间
3. 选择方向，输入 CORN 数量，页面实时显示预估收益
4. 点击下注：
   - **首次**会先弹"授权 CORN"交易 → 确认
   - 再弹"下注"交易 → 确认
5. 成功后可在 **底部导航 投资** 页看到持仓

> 提示：赔率由资金池自动计算——注少的一边可能回报更高；最终收益按结算时两边资金池计算，页面显示为估算值。

---

## 6. 领取奖励

市场结算后（结果已定），点 **底部导航 投资** 页的"领取奖励"：

- 赢家：领回本金 + 按份额分到的奖励
- 输家：没有奖励，本金进入奖池分配给赢家
- 每个市场只能领取一次

## 7. 费率说明（重点）

| 项目 | 说明 |
|------|------|
| **平台手续费** | 默认 **2%**，从输家的资金池中扣除 |
| 手续费上限 | 单个市场最高 10%（创建者可设置更低/更高） |
| 手续费去向 | 自动转入 **feeCollector**（平台收款账号），用于运营 |
| **创建市场** | 免费，只需 Gas |
| **下注 / 领取** | 无平台费，只需少量 ETH Gas（测试网几乎免费） |
| **争议押金** | 发起争议需支付固定押金（CORN），争议通过退回，驳回则没收 |

### 手续费怎么算（示例）

默认费率 200 bps（2%）。假如：
- YES 边共下注 1000 CORN，NO 边共下注 500 CORN，最终 YES 赢
- 平台手续费 = 500 × 2% = **10 CORN**
- 奖励池 = 500 − 10 = **490 CORN**，由全部 YES 下注者按份额瓜分
- 你下了 100 CORN：拿回 100 本金 + 100 × (490/1000) = **149 CORN**（净赚 49）

> 简单说：**输家资金池的 98% 归赢家，2% 归平台。**

## 8. 创建市场

> 仅限被授权的地址（Owner 或 marketCreator）。普通用户无法直接创建。

1. **更多 → 创建市场**
2. 填写：问题描述、投票截止时间、自定义费率（留空则用默认 2%）
3. 确认交易 → 市场发布到首页

授权与撤销创建权限：**更多 → 创建权限管理**（仅 Owner 可用）。

---

## 9. 争议（HumanHouse）

对结算结果有异议时，可在 **更多 → HumanHouse 争议** 发起争议：

1. 选择市场，填写争议原因，支付押金（CORN）
2. 社区入会用户投票（YES 支持异议 / NO 维持原判）
3. 投票期约 5 天；支持票过半则反转结果并退回押金

> 当前版本 **World ID（人证合一）为模拟实现**，正式集成即将上线；以合约投票为准。

## 10. 治理参与

1. **更多 → 委托管理**：把 CORN 存为 govCORN（1:1），并把投票权委托给自己或他人
2. **治理页**：查看提案、投票
3. 持有 govCORN 达标（≥ 总供应量 1%）可在合约层面发起提案

## 12. 常见问题（FAQ）

| 问题 | 解决 |
|------|------|
| 点 MetaMask 没反应 / 停在"正在连接" | 检查 VPN 是否全局接管、网络是否稳定；深链调不起需确保钱包已安装 |
| 提示"网络错误/加载失败" | 到"网络设置"切换 RPC 节点 |
| 下注提示"授权不足" | App 会先引导授权，确认两次交易即可 |
| 钱包没 ETH | 测试网 ETH 从水龙头领取，用于 Gas |
| 创建市场按钮不可用 | 当前地址未被授权为 marketCreator |
| 想取消已下注 | 下注不可撤回，只能等待结算。下注前请确认方向 |

### 14.2 修改费率（setDefaultFee）

`PredictionMarket.setDefaultFee(uint16 _feeBps)` 修改**所有新建市场的默认费率**（不影响已创建的市场）。费率上限 1000 bps = 10%。

对应调用数据（calldata 开头）：
- 函数选择器：`0x77326584`
- 示例：设为 3% → 调 `setDefaultFee(300)`

```
cast call 0x9cb69cb7da9677b3a122a6a4e402398a6df4a026 \
  "setDefaultFee(uint16)" 300 --rpc-url <RPC>
```

> 用 Owner 钱包签名发送到合约地址 `0x9cb69c...` 即可（配合 cast send，或用已连接 Owner 的钱包 App 发起）。

### 14.3 修改收款账号（setFeeCollector）

`PredictionMarket.setFeeCollector(address _feeCollector)` 修改手续费转入地址，**立即对所有后续结算生效**。

- 函数选择器：`0xa42dce80`
- 示例：换成收款账号 `0x...NewAddress` → 调 `setFeeCollector(0x...NewAddress)`

### 14.5 上线前检查清单

1. **收款账号分离**：将 `feeCollector` 从 Owner 改为独立运营收款地址
2. **确认费率**：上线主网前确认 `defaultFeeBps` 是否符合运营策略（2% 或另设 ≤10%）
3. **授权创建者**：用 owner 在 App「创建权限管理」授权市场创建者名单
4. **权限隔离**：CornToken 的 minter/owner 权限应移交给治理或多签，避免单点
5. 以上修改全部**上链即生效、不可回滚**（已生效的市场仍按各自费率和原收款账号结算），请先在测试网演练
