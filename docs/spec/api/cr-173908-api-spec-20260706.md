## 1. HumanHouse（争议/人类院）

### Requirement: 争议押金与状态机
系统 SHALL 在 `raiseDispute` 时冻结调用者 CORN 押金；争议状态 SHALL 从 `ACTIVE` 经投票后进入 `UPHELD`/`REJECTED`。

#### Scenario: 发起争议冻结押金
- GIVEN 调用者持有 ≥ `disputeDeposit` 的 CORN
- WHEN 调用 `raiseDispute(marketId, reason)`
- THEN 调用者 CORN 余额减少 `disputeDeposit`，且 `disputes[marketId].status == ACTIVE`

#### Scenario: 重复投票回滚
- GIVEN 投票者已对 `marketId` 投过票
- WHEN 再次调用 `vote(marketId, support)`
- THEN 交易回滚，error 含字符串 `"already voted"`

#### Scenario: 投票期外回滚
- GIVEN `block.timestamp > raiseDispute 时间 + votingPeriod`
- WHEN 调用 `vote(marketId, support)`
- THEN 交易回滚，error 含字符串 `"voting ended"`

#### Scenario: 投票窗未结束不可执行
- GIVEN `block.timestamp < raiseDispute 时间 + votingPeriod`
- WHEN 调用 `executeDispute(marketId)`
- THEN 交易回滚，error 含字符串 `"voting not ended"`

#### Scenario: 二次执行回滚
- GIVEN `disputes[marketId].status` 已非 `ACTIVE`
- WHEN 再次调用 `executeDispute(marketId)`
- THEN 交易回滚，error 含字符串 `"not active"`

#### Scenario: 驳回后没收押金由 owner 提取
- GIVEN `executeDispute` 结果为 `REJECTED`（多数反对）
- WHEN owner 调用 `withdrawFees()`
- THEN 被没收的 `disputeDeposit` 转入 owner，且 `disputes[marketId]` 费用清零

### Requirement: 参数仅 owner 可设
系统 SHALL 仅允许 owner 调用 `setDisputeDeposit` / `setVotingPeriod`；非 owner 调用 MUST 回滚。

### Requirement: 信任层 stub（D1/D3）
系统 SHALL 以 `_verifyWorldId()` 返回 `true` 作为信任层 stub；测试 SHALL NOT 传入 World ID 证明参数。

## 2. GovCrownToken（治理代币）

### Requirement: 包装 1:1 完整性
系统 SHALL 保证 `wrap`/`depositFor` 锁定的 CORN 与 `govCORN.totalSupply` 1:1 对应。

#### Scenario: 1:1 包装完整性
- GIVEN 调用者 `depositFor(recipient, amount)` 锁定 `amount` CORN
- WHEN 查询 `totalSupply()`
- THEN `totalSupply == 锁定 CORN 总量`

### Requirement: 委托前投票权为零
系统 SHALL 在委托前返回 `getVotes(account) == 0`。

#### Scenario: 委托前无投票权
- GIVEN 账户持有 govCORN 但未 `delegate`
- WHEN 查询 `getVotes(account)`
- THEN 返回 `0`

### Requirement: 委托链路
系统 SHALL 在 `delegate(delegatee)` 后将投票权转移至 `delegatee`。

## 4. 部署不变量（DeployDryRun）

### Requirement: 所有权转移不变量
部署脚本 `Deploy.s.sol` + `TransferToTimelock.s.sol` 执行后，系统 SHALL 满足：

#### Scenario: 市场与代币归属 Timelock
- GIVEN 部署并转移所有权完成
- WHEN 查询 `market.owner()` 与 `token.owner()`
- THEN 二者均等于 `Timelock` 地址

#### Scenario: Timelock 自管 admin
- GIVEN Timelock 已部署
- WHEN 查询 `Timelock.admin()`
- THEN 等于 `Timelock` 自身地址

#### Scenario: 多签与执行者角色
- GIVEN 治理角色已配置
- WHEN 查询 proposer / executor
- THEN proposer 为 Safe 多签，executor 为 `address(0)`

## 5. 测试回滚字符串权威表

| 函数 | 条件 | 回滚字符串 |
|------|------|-----------|
| `vote` | 已投 | `"already voted"` |
| `vote` | 过投票期 | `"voting ended"` |
| `executeDispute` | 窗未结束 | `"voting not ended"` |
| `executeDispute` | 非 ACTIVE | `"not active"` |
| `setDisputeDeposit` / `setVotingPeriod` | 非 owner | 默认 Ownable 回滚 |
| `withdrawFees` | 非 owner | 默认 Ownable 回滚 |
